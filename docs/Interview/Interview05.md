### What are the main components of GCP?

The main component of the GCP includes Compute, Storage, Networking, Databases and Big Data and AI services.  
Compute services include Compute Engine, App Engine, GKE.  
The storage include Cloud storage, persistent disk and file store.
The network service include VPC, Load balancer, Cloud CDNs.
The database service include CloudSQL, Fire store, Big table and Spanner.
The big data tool include big query and data flow.


### What is the compute engine in GCP?
The compute engine is Google Cloud's Infrastructure As A Code (IAS) offerings that allows to  create and run VMs. The VMs run Linux or windows OS and compute engine provides flexible machine types, custom VM configuration and autoscaling. 

It integrates with other GCP service like cloud storage and VPC network and user can select preemptable VMs for cost savings.

Example - A company hosting a legacy application can migrate it to compute engine without changing major code.


### What is Cloud Storage?

Cloud Storage is GCP's object storage service used to store unstructured data like images, volume and backups. The cloud storage offers different storage classes like standard, nearline, coldline and archieve.

### What is a Service account? 

A service account is a special type of account used by the application or the VMs to interact with the GCP services. Unlike the user account the service account is not tied with the individual and they use keys or tokens to authenticate.
